# Evidencias históricas del modelo V1

Estas capturas y la validación técnica pertenecen al modelo anterior: 432 compradores ficticios, 4.909 pedidos y 22.894 detalles limpios. No acreditan la versión V2.

El modelo V1 quedó publicado en el commit d81d873cd2004164bb0cdb330f045efe1a54add9. El historial de Git conserva sus scripts y CSV completos.

La V2 utiliza los establecimientos reales como clientes de un mayorista ficticio y un pedido mensual por establecimiento. Las capturas actuales de pgAdmin se solicitarán después de cargar V2. La captura del antiguo top 5 recibida en el chat tampoco es válida para V2.
